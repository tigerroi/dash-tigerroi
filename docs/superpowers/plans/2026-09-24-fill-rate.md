# Rasio Penayangan Ad Exchange per Jam — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tab Overview baru yang menggambar Total permintaan, Tayangan, dan Rasio penayangan Ad Exchange per jam WIB (per domain/subdomain), dari data yang ditarik server kontrol tiap 10 menit ke RTDB dan tidak pernah dihapus.

**Architecture:** `functions/gam.js` meminta laporan `DATE, HOUR, SITE` × 2 metrik AdX dan memetakan jam network ke jam WIB. `functions/fill-rate-core.js` (murni) menyusun daun RTDB, penanda `partial`, dan selisih yang perlu ditulis. `functions/sync-fill-rate.mjs` mengorkestrasi satu run, dan dipanggil cron server kontrol. Di browser, `src/lib/fillRate.js` (murni) meratakan pohon RTDB jadi baris, deret grafik, dan tabel. `src/components/FillRate.jsx` menggambar tiga grafik Recharts + `DataTable`, dan dipasang sebagai tab `/dashboard/rasio-penayangan`.

**Tech Stack:** Node 22 (`functions/`, `node --test`), Bun + Elysia + `@elysiajs/cron` (`server/`), React + Recharts + Firebase RTDB client SDK (`src/`), Biome.

**Spec:** `docs/superpowers/specs/2026-09-24-fill-rate-design.md`

## Global Constraints

- Metrik: `AD_EXCHANGE_TOTAL_REQUESTS` (label **Total permintaan Ad Exchange**) dan `AD_EXCHANGE_IMPRESSIONS` (label **Tayangan Iklan Ad Exchange**). Rasio = tayangan ÷ permintaan × 100, label **Rasio penayangan Ad Exchange**. Jangan pernah memakai label "Total rasio pengisian".
- Agregasi di tingkat mana pun: Σtayangan ÷ Σpermintaan, bukan rata-rata rasio.
- Permintaan 0 → rasio `null` (garis terputus), tidak pernah 0% atau Infinity.
- Jam dalam WIB (`Asia/Jakarta`). Tanggal lewat `zonedDateKey`, bukan `toISOString().slice(0,10)`.
- Bentuk node: `dashboard/fillRate/{YYYY-MM-DD}/{siteKey}/h{HH} = { req, imp, partial? }`. Kunci jam `h00`…`h23`. Kunci status network `n{networkCode}`.
- `siteKey`: hostname huruf kecil, titik → koma. Situs yang bukan hostname → `_net_{domain akun GAM, titik → koma}`.
- Node `dashboard/fillRate` TIDAK PERNAH dihapus/dipangkas oleh kode mana pun.
- Hanya daun yang berubah yang ditulis; run tanpa perubahan tidak memanggil `update` ke `dashboard/fillRate`.
- Cron server kontrol tiap 10 menit (`FILL_RATE_CRON`, bawaan `"5 */10 * * * *"`, enam bidang, detik di depan).
- Tab: `/dashboard/rasio-penayangan`, label `Rasio Penayangan`, `key: "dashboard"`.
- Warna grafik hanya dari `useChartPalette` + `seriesColor`; tidak ada hex di JSX/CSS di luar blok token.
- Tidak ada `<table>` di luar `DataTable`, tidak ada `<select>` mentah (pakai `SelectField`).
- Pesan commit TANPA trailer `Co-Authored-By` (aturan CLAUDE.md repo ini).
- Tidak butuh `npm run deploy:rules`.

// --- Rasio penayangan Ad Exchange per JAM WIB ---------------------------------------------------
//
// `rekeyToSyncDays` di atas MENJUMLAHKAN jam-jam ke hari WIB dan membuang jamnya; tab Rasio
// Penayangan justru butuh jamnya. Jadi tiap jam network dipetakan ke tanggal DAN jam WIB-nya, dengan
// `hourInstant` yang sama. `AD_REQUESTS` (Total panggilan iklan) DITOLAK bersama HOUR (dibuktikan
// ke produksi 24 Sep 2026); pasangan AdX ini diterima dan cocok sampai angka terakhir dengan layar
// Laporan interaktif Ad Manager.
export const FILL_RATE_METRICS = ["AD_EXCHANGE_TOTAL_REQUESTS", "AD_EXCHANGE_IMPRESSIONS"];

function hourKeyIn(ms, timeZone) {
  const hour = new Intl.DateTimeFormat("en-GB", { timeZone, hour: "2-digit", hourCycle: "h23" })
    .format(new Date(ms));
  return hour.padStart(2, "0");
}

export function wibHourRows(rows, networkZone, range, targetZone = targetTimeZone()) {
  const from = dayKey(range.startDate);
  const until = dayKey(range.endDate);
  const merged = new Map();
  for (const row of rows || []) {
    const [date, hour, site = ""] = (row.dimensionValues || []).map((v) =>
      v?.stringValue != null ? v.stringValue : String(v?.intValue ?? ""),
    );
    const at = hourInstant(date, hour, networkZone || targetZone);
    const day = dateKeyIn(at, targetZone);
    if (day < from || day > until) continue;
    const wibHour = hourKeyIn(at, targetZone);
    const [req = 0, imp = 0] = (row.metricValueGroups?.[0]?.primaryValues || []).map(numeric);
    const id = `${day}|${wibHour}|${site}`;
    const prev = merged.get(id);
    if (prev) {
      prev.req += req;
      prev.imp += imp;
    } else {
      merged.set(id, { date: day, hour: wibHour, site, req, imp });
    }
  }
  return [...merged.values()];
}

import { shiftDateKey, zonedDateKey } from "./sync-core.js";

/**
 * Rasio penayangan Ad Exchange per jam — aturan murni penyimpanannya.
 *
 * Node ini TIDAK PERNAH dipangkas. Yang membuatnya tetap murah dibuka adalah kuncinya: tanggal di
 * tingkat pertama, jadi halaman meminta rentangnya saja (`orderByKey().startAt().endAt()`).
 *
 * KUNCI JAM BERAWALAN HURUF (`h05`, bukan `05`). SDK Firebase membaca kunci berbentuk angka — nol
 * di depan pun diterima — sebagai indeks, dan node jam yang hampir penuh kembali sebagai ARRAY
 * berlubang. Alasan yang sama dengan `c57` di antrean gating dan `n{networkCode}` di status.
 */
export const FILL_RATE_PATH = "dashboard/fillRate";
export const FILL_RATE_STATUS_PATH = "dashboard/fillRateStatus";
export const NET_PREFIX = "_net_";

// Titik jadi koma (bisa dibaca balik di browser: hostname tidak pernah memuat koma); karakter lain
// yang ditolak RTDB jadi garis bawah.
const encode = (value) =>
  String(value)
    .trim()
    .toLowerCase()
    .replace(/\./g, ",")
    .replace(/[#$/[\]]/g, "_");

const isHostname = (site) => /^[a-z0-9-]+(\.[a-z0-9-]+)+$/i.test(String(site || "").trim());

/**
 * Hostname -> kunci. Yang bukan hostname ("(Not applicable)": permintaan yang tidak bisa dikaitkan
 * ke situs mana pun) masuk ember network berkunci DOMAIN akun GAM-nya, supaya total domain sama
 * dengan total network di layar GAM dan browser bisa menaruhnya di domain yang benar tanpa membaca
 * `gamAccounts` (ADMIN_ONLY).
 */
export function siteKey(site, networkDomain = "", networkCode = "") {
  if (isHostname(site)) return encode(site);
  return `${NET_PREFIX}${encode(networkDomain || networkCode || "unknown")}`;
}

export const networkStatusKey = (code) => `n${code}`;

const slotOf = (row) => `${row.date}T${row.hour}`;

/**
 * Baris satu network -> daun RTDB. Jam TERAKHIR yang dilaporkan network itu bertanda `partial`:
 * permintaan tercatat lebih lambat daripada tayangan, jadi rasio jam itu selalu melonjak palsu
 * (stylefemale jam 11 68,9%, sheetz jam 9 94,8% — 24 Sep 2026). Run berikutnya menimpanya tanpa
 * tanda begitu jam sesudahnya muncul.
 */
export function fillRateLeaves(rows, network = {}) {
  let lastSlot = "";
  for (const row of rows || []) {
    if (slotOf(row) > lastSlot) lastSlot = slotOf(row);
  }
  const leaves = {};
  for (const row of rows || []) {
    const path = `${row.date}/${siteKey(row.site, network.domain, network.code)}/h${row.hour}`;
    const leaf = leaves[path] || { req: 0, imp: 0 };
    leaf.req += Math.round(Number(row.req) || 0);
    leaf.imp += Math.round(Number(row.imp) || 0);
    if (slotOf(row) === lastSlot) leaf.partial = true;
    leaves[path] = leaf;
  }
  return { leaves, lastSlot };
}

// Dua network yang melaporkan hostname yang sama (jarang) dijumlahkan, bukan saling menimpa.
export function addLeaves(target, leaves) {
  for (const [path, leaf] of Object.entries(leaves || {})) {
    const prev = target[path];
    if (!prev) {
      target[path] = { ...leaf };
      continue;
    }
    prev.req += leaf.req;
    prev.imp += leaf.imp;
    if (leaf.partial) prev.partial = true;
  }
  return target;
}

export function flattenFillRate(tree) {
  const out = {};
  for (const [date, sites] of Object.entries(tree || {})) {
    for (const [key, hours] of Object.entries(sites || {})) {
      for (const [hour, leaf] of Object.entries(hours || {})) {
        out[`${date}/${key}/${hour}`] = leaf;
      }
    }
  }
  return out;
}

const sameLeaf = (a, b) =>
  Boolean(a) &&
  Number(a.req) === b.req &&
  Number(a.imp) === b.imp &&
  Boolean(a.partial) === Boolean(b.partial);

/**
 * Hanya daun yang BERUBAH — termasuk yang cuma kehilangan tanda `partial`. Jam yang sudah final
 * tidak ditulis ulang, jadi tab yang terbuka menerima delta beberapa jam terakhir, bukan seluruh
 * hari tiap sepuluh menit. Daun ditulis UTUH (bukan per field), supaya `partial` yang lepas
 * benar-benar hilang dari RTDB. Yang TIDAK ada di `next` tidak pernah dihapus.
 */
export function changedLeaves(previous, next) {
  const out = {};
  for (const [path, leaf] of Object.entries(next || {})) {
    if (!sameLeaf(previous?.[path], leaf)) out[path] = leaf;
  }
  return out;
}

const gamDay = (key) => {
  const [year, month, day] = key.split("-").map(Number);
  return { year, month, day };
};

// Kemarin + hari ini, SATU laporan: jam-jam akhir kemarin baru final lewat tengah malam.
export function fillRateWindow(now = new Date()) {
  const to = zonedDateKey(now);
  const from = shiftDateKey(to, -1);
  return { from, to, range: { startDate: gamDay(from), endDate: gamDay(to) } };
}

import {
  addLeaves,
  changedLeaves,
  FILL_RATE_PATH,
  FILL_RATE_STATUS_PATH,
  fillRateLeaves,
  fillRateWindow,
  flattenFillRate,
  networkStatusKey,
} from "./fill-rate-core.js";
import { runNetworkHourlyFillRate } from "./gam.js";
import { asStore } from "./store.mjs";
import {
  accountToken,
  displayStamp,
  earningAccounts,
  SYNC_ISSUES_PATH,
  syncIssuesUpdate,
} from "./sync-core.js";

const defaultFetch = (account, range, token) =>
  runNetworkHourlyFillRate(String(account.networkCode), range, token);

/**
 * Satu run tab Rasio Penayangan: satu laporan per network GAM (kemarin + hari ini), lalu HANYA
 * daun yang berubah ditulis. Dijalankan cron server kontrol tiap 10 menit — terpisah dari sync
 * penuh, supaya jam yang baru diterbitkan GAM tidak menunggu tahap ROI/Meta.
 *
 * Tidak ada antrean retry: run berikutnya sepuluh menit lagi sudah jadi retry-nya. Tidak ada yang
 * DIHAPUS, termasuk data network yang gagal run ini.
 */
export async function syncFillRate(
  dbOrStore,
  { now = new Date(), fetchHourly = defaultFetch, tokenOf = accountToken } = {},
) {
  const store = asStore(dbOrStore);
  const [gamAccounts, configs] = await Promise.all([
    store.read("gamAccounts"),
    store.read("googleApiConfigs"),
  ]);
  const accounts = earningAccounts(gamAccounts, null).filter((entry) => entry.provider === "gam");
  const window = fillRateWindow(now);

  // Satu tukar token per kredensial per run. Promise yang GAGAL ikut tersimpan: seluruh akun
  // berkredensial itu memang gagal untuk alasan yang sama.
  const tokens = new Map();
  const tokenFor = (account) => {
    const key = account.googleCredential || "";
    if (!tokens.has(key)) tokens.set(key, tokenOf(account, configs));
    return tokens.get(key);
  };

  const results = await Promise.all(
    accounts.map(async ({ account, label }) => {
      try {
        const token = await tokenFor(account);
        return { account, label, rows: await fetchHourly(account, window.range, token) };
      } catch (error) {
        return { account, label, error };
      }
    }),
  );

  const next = {};
  const networks = {};
  const issues = [];
  for (const { account, label, rows, error } of results) {
    const code = String(account.networkCode);
    if (error) {
      networks[networkStatusKey(code)] = { name: label, ok: false, message: error.message };
      issues.push({
        source: "Rasio Penayangan",
        target: label,
        message: error.message,
        impact: "Grafik Rasio Penayangan network ini berhenti di tarikan terakhir yang berhasil.",
        credential: account.googleCredential || "",
      });
      continue;
    }
    const domain = String(account.name || "").trim().toLowerCase();
    const { leaves, lastSlot } = fillRateLeaves(rows, { domain, code });
    addLeaves(next, leaves);
    networks[networkStatusKey(code)] = { name: label, ok: true, lastSlot };
  }

  const previous = flattenFillRate(await store.readFrom(FILL_RATE_PATH, window.from));
  const writes = changedLeaves(previous, next);
  const written = Object.keys(writes).length;
  if (written) await store.update(FILL_RATE_PATH, writes);

  // Stempel WIB tanpa zona (`displayStamp`), sesuai aturan stempel sync.
  await store.replace(FILL_RATE_STATUS_PATH, { lastRunAt: displayStamp(now), networks });
  await store.replace(
    `${SYNC_ISSUES_PATH}/fillRate`,
    syncIssuesUpdate("Rasio Penayangan", issues, now),
  );
  return { networks: accounts.length, failed: issues.length, written };
}

export function subDomainNames(rows) {

  for (const row of rows || []) {

/**
 * Tab Rasio Penayangan — sisi browser. Node-nya ditulis `functions/sync-fill-rate.mjs`:
 * `dashboard/fillRate/{YYYY-MM-DD}/{siteKey}/h{HH} = { req, imp, partial? }`.
 *
 * `decodeSiteKey` adalah CERMIN `siteKey` di functions/fill-rate-core.js (titik jadi koma, ember
 * `_net_{domain}` untuk permintaan tanpa situs). Dijaga fillRate.test.mjs, yang mengimpor berkas
 * seberangnya — beda sedikit, satu domain berbunyi dua nama di tab ini tanpa error di mana pun.
 */
export const FILL_RATE_PATH = "dashboard/fillRate";
export const FILL_RATE_STATUS_PATH = "dashboard/fillRateStatus";
export const NET_PREFIX = "_net_";
export const TOP_SERIES = 8;
export const OTHER_LABEL = "Lainnya";
// Ujung rentang yang dikosongkan dijepit: node ini tidak pernah dipangkas, dan "semua tanggal"
// berarti unduhan yang tumbuh tiap hari.
export const MAX_OPEN_DAYS = 31;

const OPERATION_ZONE = "Asia/Jakarta";
const NET_LABEL = "(tanpa situs) ";

export function decodeSiteKey(key) {
  const text = String(key || "");
  if (text.startsWith(NET_PREFIX)) {
    const domain = text.slice(NET_PREFIX.length).replace(/,/g, ".");
    // Tanpa titik = kode network (akun tanpa nama domain), bukan domain.
    return { host: "", netDomain: domain.includes(".") ? domain : "" };
  }
  return { host: text.replace(/,/g, "."), netDomain: "" };
}

export const netLabel = (domain) => `${NET_LABEL}${domain || "?"}`;

export function fillRateRows(tree) {
  const rows = [];
  for (const [date, sites] of Object.entries(tree || {})) {
    for (const [key, hours] of Object.entries(sites || {})) {
      const { host, netDomain } = decodeSiteKey(key);
      const subDomain = host || netLabel(netDomain);
      for (const [hourKey, leaf] of Object.entries(hours || {})) {
        rows.push({
          date,
          hour: hourKey.replace(/^h/, ""),
          subDomain,
          netDomain,
          req: Number(leaf?.req) || 0,
          imp: Number(leaf?.imp) || 0,
          partial: leaf?.partial === true,
        });
      }
    }
  }
  return rows;
}

// Indeks pemilik (subDomainOwnerIndex) yang juga mengenal ember network: domainnya tertulis di
// labelnya sendiri, dan ia tidak punya PIC — memilih advertiser membuangnya, karena ia bukan milik
// siapa pun.
export function fillRateOwners(owners) {
  const isNet = (name) => String(name || "").startsWith(NET_LABEL);
  return {
    domainOf: (name) => (isNet(name) ? String(name).slice(NET_LABEL.length).replace(/^\?$/, "") : owners.domainOf(name)),
    picOf: (name, pic) => (isNet(name) ? "" : owners.picOf(name, pic)),
  };
}

// Permintaan 0 tidak punya rasio: null memutus garis Recharts, sepola getNetPercentage.
export function rateOf(req, imp) {
  return req > 0 ? (imp / req) * 100 : null;
}

export function formatRate(value) {
  return Number.isFinite(value)
    ? `${value.toLocaleString("id-ID", { minimumFractionDigits: 2, maximumFractionDigits: 2 })}%`
    : "-";
}

/**
 * Deret grafik: satu titik per jam, satu seri per rincian (domain atau subdomain). Rasio tiap seri
 * dan total dihitung dari JUMLAH (Σimp ÷ Σreq), bukan rata-rata rasio. Rincian dibatasi 8 teratas
 * menurut permintaan; sisanya satu seri "Lainnya".
 */
export function fillRateSeries(rows, owners, level) {
  const groupOf = (row) =>
    level === "domain" ? owners.domainOf(row.subDomain) || "(domain tidak diketahui)" : row.subDomain;

  const volume = new Map();
  for (const row of rows) volume.set(groupOf(row), (volume.get(groupOf(row)) || 0) + row.req);
  const ranked = [...volume.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
    .map(([name]) => name);
  const labels = ranked.length > TOP_SERIES ? [...ranked.slice(0, TOP_SERIES), OTHER_LABEL] : ranked;
  const series = labels.map((label, index) => ({ id: `s${index}`, label }));
  const idOf = new Map(series.map((item) => [item.label, item.id]));

  const slots = new Map();
  for (const row of rows) {
    const slot = `${row.date}T${row.hour}`;
    const point =
      slots.get(slot) ||
      { slot, date: row.date, hour: row.hour, partial: false, totalReq: 0, totalImp: 0 };
    slots.set(slot, point);
    const id = idOf.get(groupOf(row)) || idOf.get(OTHER_LABEL);
    point[`${id}Req`] = (point[`${id}Req`] || 0) + row.req;
    point[`${id}Imp`] = (point[`${id}Imp`] || 0) + row.imp;
    point.totalReq += row.req;
    point.totalImp += row.imp;
    if (row.partial) point.partial = true;
  }

  const points = [...slots.values()].sort((a, b) => a.slot.localeCompare(b.slot));
  for (const point of points) {
    for (const { id } of series) {
      point[`${id}Req`] = point[`${id}Req`] || 0;
      point[`${id}Imp`] = point[`${id}Imp`] || 0;
      point[`${id}Rate`] = rateOf(point[`${id}Req`], point[`${id}Imp`]);
    }
    point.totalRate = rateOf(point.totalReq, point.totalImp);
  }
  return { series, points };
}

// Ruas jam `partial` digambar putus-putus. Titik tepat sebelum titik partial ikut ruas putus-putus
// supaya kedua ruas bersambung — aturan yang sama dengan `withRoiSeries` di RoiCurveChart.
export function dashedSplit(points, keys) {
  return points.map((point, index) => {
    const next = points[index + 1];
    const dashed = point.partial || (next?.partial === true && !point.partial);
    const out = { ...point };
    for (const key of keys) {
      out[`${key}Solid`] = point.partial ? null : point[key];
      out[`${key}Dashed`] = dashed ? point[key] : null;
    }
    return out;
  });
}

export function siteTotals(rows, owners, registered) {
  const bySite = new Map();
  for (const row of rows) {
    const total =
      bySite.get(row.subDomain) ||
      { subDomain: row.subDomain, domain: owners.domainOf(row.subDomain), req: 0, imp: 0, net: Boolean(row.netDomain) || row.subDomain.startsWith(NET_LABEL) };
    total.req += row.req;
    total.imp += row.imp;
    bySite.set(row.subDomain, total);
  }
  return [...bySite.values()]
    .map(({ net, ...total }) => ({
      ...total,
      rate: rateOf(total.req, total.imp),
      unregistered: !net && !registered.has(total.subDomain.toLowerCase()),
    }))
    .sort((a, b) => b.req - a.req || a.subDomain.localeCompare(b.subDomain));
}

function wibDateKey(now = new Date()) {
  return new Intl.DateTimeFormat("en-CA", { timeZone: OPERATION_ZONE }).format(now);
}

function shiftKey(key, days) {
  const base = new Date(`${key}T12:00:00Z`);
  base.setUTCDate(base.getUTCDate() + days);
  return base.toISOString().slice(0, 10);
}

// "Hari ini" versi OPERASI (WIB), bukan jam perangkat — baris ditulis dengan tanggal WIB.
export function wibTodayRange(now = new Date()) {
  const key = wibDateKey(now);
  return { from: key, to: key };
}

export function boundedRange({ from = "", to = "" } = {}, now = new Date()) {
  const end = to || wibDateKey(now);
  return { from: from || shiftKey(end, -(MAX_OPEN_DAYS - 1)), to: end };
}

export function slotLabel(point, multiDay) {
  const hour = `${point.hour}:00`;
  return multiDay ? `${formatDayMonth(point.date)} ${hour}` : hour;
}

import { endAt, onValue, orderByKey, query, ref, startAt } from "firebase/database";
import { useEffect, useState } from "react";
import { database } from "../config/firebase";
import { FILL_RATE_PATH, FILL_RATE_STATUS_PATH } from "../lib/fillRate";

/**
 * Langganan tab Rasio Penayangan. BUKAN lewat store/useStickyValue: node ini tidak pernah
 * dipangkas, jadi yang diunduh HARUS rentang yang dipilih saja — kunci tingkat pertamanya tanggal,
 * jadi `orderByKey().startAt().endAt()` menyaringnya di server. Dipasang ulang saat rentang
 * berganti; live, jadi jam yang baru ditarik cron muncul tanpa muat ulang.
 */
export function useFillRate({ from, to }) {
  const [data, setData] = useState({ loading: true, error: "", tree: null });
  const [status, setStatus] = useState(null);

  useEffect(() => {
    setData((prev) => ({ ...prev, loading: true }));
    return onValue(
      query(ref(database, FILL_RATE_PATH), orderByKey(), startAt(from), endAt(to)),
      (snapshot) => setData({ loading: false, error: "", tree: snapshot.val() || {} }),
      (error) => setData((prev) => ({ ...prev, loading: false, error: error.message })),
    );
  }, [from, to]);

  useEffect(
    () => onValue(ref(database, FILL_RATE_STATUS_PATH), (snapshot) => setStatus(snapshot.val())),
    [],
  );

  return { ...data, status };
}

// Umur data: halaman yang menjanjikan realtime harus menyebut kapan terakhir ditarik.
function StatusLine({ status }) {
  if (!status?.lastRunAt) return <p>Belum pernah ditarik.</p>;
  const networks = Object.values(status.networks || {});
  const failed = networks.filter((item) => !item.ok).map((item) => item.name);
  const last = networks.map((item) => item.lastSlot || "").sort().at(-1);
  return (
    <p>
      Ditarik {formatDateTime(status.lastRunAt)} WIB
      {last ? ` · jam terakhir ${last.slice(11)}:00 (belum lengkap)` : ""}
      {failed.length ? ` · gagal ditarik: ${failed.join(", ")}` : ""}
    </p>
  );
}

function SeriesLegend({ chart, series, hasPartial }) {
  return (
    <div className="chart-legend">
      {series.map((item, index) => (
        <span key={item.id}>
          <i className="legend-dot" style={{ background: seriesColor(chart, index) }} /> {item.label}
        </span>
      ))}
      {hasPartial && (
        <span className="legend-running">
          <i className="legend-dash" /> Jam terakhir — belum lengkap
        </span>
      )}
    </div>
  );
}

function SlotTooltip({ active, payload, series }) {
  if (!active || !payload?.length) return null;
  const point = payload[0].payload;
  const lines = series.length ? series.filter((item) => point[`${item.id}Req`] > 0) : [];
  return (
    <div className="recharts-tooltip-card">
      <strong>{point.label}</strong>
      {point.partial && <span className="chart-tooltip-running">Jam terakhir, belum lengkap</span>}
      <span>
        Total: {count(point.totalReq)} permintaan · {count(point.totalImp)} tayangan · {formatRate(point.totalRate)}
      </span>
      {lines.map((item) => (
        <span key={item.id}>
          {item.label}: {count(point[`${item.id}Req`])} · {count(point[`${item.id}Imp`])} · {formatRate(point[`${item.id}Rate`])}
        </span>
      ))}
    </div>
  );
}
